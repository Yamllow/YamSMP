How to join

Add the server once and it stays in your list. Pick the steps for the version of Minecraft you play.

Java Edition (PC)

  1. Open Minecraft.
  2. Go to Multiplayer, then Add Server.
  3. Type in the Server Address box.
  4. Click Done, then double-click YamSMP to join.

Bedrock Edition (mobile, console, Windows)

  1. Open Minecraft and tap Play, then the Servers tab.
  2. Scroll down and choose Add Server.
  3. Name it YamSMP. Address: Port:
  4. Save, then tap YamSMP in your server list to join.

Can't connect? Check the server status on the Home page, then ask for help in our Discord.

    2. Find the ticket channel and open a new ticket.

    4. Staff will reply in your ticket and help you finish the purchase.
